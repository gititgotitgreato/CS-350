This project was to make a GPIO and I2C-based thermostat that can tell the room temperature from an I2C temperature sensor, compare it to a set point and change LED states based on it, display the set point, temperature, state and time on an LCD screen, allow the user to change states, increase and decrease the setpoint from three buttons, and periodically print output serially to another program. Assembling the circuit was a straightforward process, and the code was easy to make from the template I was given. The only thing I really struggled with was an I2C error that occasionally crashed the program when changing states, which required me to research I2C and implement a lock on the Fahrenheit conversion function so the system stays stable. I usually use PyCharm or a like IDE for Python projects, but since this class used templates, Visual Studio was the default IDE on my PC, and it made me realize how good of a development environment it is for any language, so for now on, it will be my default IDE for any language it supports. Embedded systems are a huge part of the computer science industry; so the experience I gained from this class will help me with future projects involving any hardware that uses GPIO or I2C input. It was also my first time using a Raspberry Pi or managing a Linux file structure, so this will help me greatly with smaller individual projects and if I get employed at a company that primarily uses Linux. I made sure that all of the code in this project is as readable and recyclable as possible by using the simplest functions I could for what I need those functions to do and making sure all of my code is properly indented and all unnecessary whitespace is clean up prior to completion.
